System Architecture & Engineering Judgement
Slide 3 / 6
  • Zero-Dependency Assessor UX: Portable SQLite database with @prisma/adapter-better-sqlite3 driver adapter—clones and boots instantly without external Docker or cloud DB setup.
  • Pure Functional Business Logic: lib/fine-calculator.ts isolates fine calculation and loan periods from HTTP/database side effects.
  • Defense in Depth (15% Security Weight):
    • NextAuth.js session verification at route handler boundaries (401 on unauthorized)
    • Runtime schema validation with Zod (400 on malformed payload)
    • Parameterized queries via Prisma (immune to SQL injection)
    • bcryptjs salted hashing for credential storage
